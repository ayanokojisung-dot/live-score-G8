
# LIVE SCORE - COUPE DES FILIERES

## 1. Presentation du projet

Live Score est une application web qui permet de calculer et d'afficher automatiquement le classement de la Coupe des Filieres opposant GL et ARS.

Le classement est base sur les resultats des matchs.

2. Ouvrir le dossier du projet.
3. Rechercher le fichier index.html.
4. Double-cliquer sur index.html.
5. La page s'ouvre dans un navigateur.
